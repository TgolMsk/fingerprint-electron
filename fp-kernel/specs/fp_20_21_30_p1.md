# P1 补丁设计稿：fp_20_navigator_hw / fp_21_screen / fp_30_webgl

## fp_20_navigator_hw（P1，navigator 硬件与语言）

探查结论：
- `navigator.hardwareConcurrency`：`core/frame/navigator_concurrent_hardware.cc:11-13`
  （fp_00 临时钩子已挂这里，本补丁将其正式化）。
- `navigator.deviceMemory`：`core/frame/navigator_device_memory.cc`（mixin，Window+Worker 共用）。
- `navigator.platform`：`core/frame/navigator_id.cc`（NavigatorID mixin，Window+Worker 共用）。
- `navigator.language(s)`：`core/frame/navigator_language.cc`（mixin）。
- 均为 mixin → 改一处 Window/Worker 全覆盖。全部用 fp_00 的 `fp::Hook` 一行替换。
- `Device-Memory` 请求头：Client Hints 子资源路径（`frame_fetch_context.cc`），
  在 fp_10 的 metadata 改写里一并核对（device memory hint 来自 blink 侧计算，确认来源后补钩子）。

配置键：`navigator.hardwareConcurrency`、`navigator.deviceMemory`、`navigator.platform`、
`navigator.languages`。disable 名：`"navigator"`。

## fp_21_screen（P1，屏幕）

探查结论：
- JS：`core/frame/screen.cc` `GetRect(bool available)`（:172）与 `GetScreenInfo()`（:186）
  是 screen.* 的漏斗；colorDepth 走 `screen_info.depth`。
- CSS 媒体查询：`core/css/media_values.cc` `CalculateDeviceWidth/Height/ColorBits/DevicePixelRatio`。
- DPR：`local_frame.cc:1849` = InspectorDeviceScaleFactorOverride × LayoutZoomFactor，
  物理 DSF 来自 `ScreenInfo.device_scale_factor`。
- browser→renderer 唯一聚合点：`content/browser/renderer_host/render_widget_host_view_base.cc:932-954`
  `GetNewScreenInfosForUpdate()`。

改法（首选 browser 侧单点，FP-HOOK）：在 `GetNewScreenInfosForUpdate()` 返回前，
按该 WebContents 所属 BrowserContext 的 fp-config 改写 `screen_infos` 的
rect/available_rect/depth/depth_per_component/device_scale_factor。一处覆盖 JS、
CSS 媒体查询、DPR 全链路。browser 侧读 fp-config：ElectronBrowserContext 已有存储（fp_00），
经 `render_widget_host_view_base` 的 GetWebContents()/browser_context 链取到。
注意：窗口可最大化但不得超过屏幕逻辑尺寸——应用侧 demo 窗口默认 1280×800，满足。
blink 侧备选：`screen.cc:172/186` 双点（需两处保持一致）。

配置键：`screen.width/height/availWidth/availHeight/colorDepth/dpr`。disable 名：`"screen"`。

## fp_30_webgl（P1，WebGL/WebGPU）

探查结论：
- `modules/webgl/webgl_rendering_context_base.cc:4202-4219` getParameter 两个 case
  （UNMASKED_VENDOR/RENDERER），WebGL1/2 共用。
- WebGPU：`modules/webgpu/gpu_adapter.cc:97-114` 构造函数字段赋值处。
- 扩展列表与 MAX_* 参数无法完全伪造 → 模板显卡档次必须与宿主机真实 GPU 接近
  （fp-generator 的模板已按此原则设计：NVIDIA 模板只在 NVIDIA 机器用——**应用侧注意**，
  后续应在 demo 里加宿主机 GPU 探测逻辑选模板）。

改法（FP-HOOK，各 1-3 行）：两个 case 返回 `fp::Hook(kWebGLVendor/kWebGLRenderer, 原值)`；
WebGPU 构造处按 `webgl.vendor/renderer` 拆写 vendor 与 description。
配置键：`webgl.vendor`、`webgl.renderer`。disable 名：`"webgl"`。
