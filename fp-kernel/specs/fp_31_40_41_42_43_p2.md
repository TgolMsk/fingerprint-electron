# P2 补丁设计稿：fp_31_canvas / fp_40_audio / fp_41_rects / fp_42_fonts / fp_43_media_speech

总原则（文档）：噪声由 seed+用途派生（fp_00 的 `NoiseUInt64/NoiseUnit`），只动读回路径，
页面显示不变；同一账号多次读取结果一致；无 fp-config 时原样返回。
**一致性红线**：同一画面的 getImageData 与 toDataURL 必须产生一致结果，否则跨 API 矛盾。

## fp_31_canvas（P1，Canvas 加噪）

探查定位（M152）：
- getImageData：`modules/canvas/canvas2d/base_rendering_context_2d.cc`
  `getImageDataInternal()`（:356），`return image_data;`（:519）前对
  `image_data->GetSkPixmap().writable_addr()` 加噪。OffscreenCanvas 2D 共用此路径。
- toDataURL/toBlob/convertToBlob 三合一单点：`platform/graphics/image_data_buffer.cc`
  `ImageDataBuffer::Create`（被 `html_canvas_element.cc:1290`、
  `canvas_async_blob_creator.cc:304/327`、`offscreen_canvas.cc`（已移至 core/）共用）。
- WebGL readPixels：`webgl_rendering_context_base.cc` `ReadPixelsHelper`（:5285），
  `ContextGL()->ReadPixels(...)`（:5358）后对 `data` 加噪（长度=width*height*组件字节，
  buffer 已经 :5327 校验）。WebGL2 全部 JS 缓冲变体汇入此函数；PBO 变体走 GPU 缓冲不经 JS。

加噪算法（fp_00 公共工具，放 `fingerprint_noise.h` 新文件）：
- 对每个像素位置 (x,y)：h = NoiseUInt64("canvas:" + x + ":" + y)
- 仅当 h % 97 == 0（约 1% 像素）时，把该像素 R 通道最低位 ^= 1（或 ±1 小扰动）
- 同一账号同一画面 → 完全相同的输出；跨账号不同
- 开关：配置 `noise.canvas` + disable 列表

## fp_40_audio（P2）

- `modules/webaudio/audio_buffer.cc`：`getChannelData`（:219 返回前包装）、
  `copyFromChannel`（:269 拷贝后）对浮点采样加 ±1e-7 级确定性扰动
  （NoiseInt("audio:"+index, -1, 1) * 1e-7）。
- `realtime_analyser.cc`：`GetFloatFrequencyData`(:101)、`GetByteFrequencyData`(:125)、
  `GetFloatTimeDomainData`(:166)、`GetByteTimeDomainData`(:192) 四个函数末尾同法处理。
- 开关：`noise.audio`。

## fp_41_rects（P2，ClientRects 与 measureText）

- `core/dom/element.cc`：`GetBoundingClientRect`（:3414 返回前）、`getClientRects`（:3362
  构造 DOMRectList 前）对坐标加 1e-5 级偏移：offset = NoiseUnit("rects:"+name) * 2e-5 - 1e-5。
- `core/dom/range.cc`：`getClientRects`(:1681)、`getBoundingClientRect`(:1695) 同策略
  （与 element 同 seed 派生，保持一致）。
- `measureText`：`base_rendering_context_2d.cc:1203`（2D/Offscreen 共用，也是字体宽度
  探测必经点）对 TextMetrics 宽度加同级偏移。
- 幅度红线：>1e-4 会导致网页布局错位，严格控制在 1e-5 级。
- 开关：`noise.rects`。

## fp_42_fonts（P2，字体白名单）

探查结论：渲染进程不枚举系统字体；网页探测字体存在性的落点是
`platform/fonts/win/font_cache_skia_win.cc:406` `CreateFontPlatformData`（家族名匹配结果）
和 `platform/fonts/font_cache.cc:198` `IsPlatformFamilyMatchAvailable`（FontFaceSet.check 依赖，
`core/css/font_face_set.cc:232/257/269`）。

改法（FP-HOOK）：
- 白名单机制：配置 `fonts: "win-default"` 映射到内核内置白名单（Windows 11 默认字体集，
  内核源码内置常量表，按模板名选择）。不在白名单的家族名 → 按"未安装"处理
  （IsPlatformFamilyMatchAvailable 返回 false；CreateFontPlatformData 走 fallback）。
- measureText 探测会被白名单自然统一（不存在字体全部落到同一 fallback 字体，宽度一致）。
- `modules/font_access/font_access.cc:173` `DidGetEnumerationResponse`：白名单过滤
  `entries`；另在 demo 侧用 `session.setPermissionRequestHandler` 拒掉 local-fonts 权限。
- 一致性：白名单必须与声称的系统匹配（win10/win11 模板各一份表）。

## fp_43_media_speech（P2，媒体设备与语音）

- `modules/mediastream/media_devices.cc` `DevicesEnumerated`（:1403 入口）改写
  `enumeration`：按常见配置返回 1 麦克风 + 1 扬声器 + 1 摄像头（无 label——
  未授权时真 Chrome 也无 label），device_id/group_id 由 seed 派生固定。
- `modules/speech/speech_synthesis.cc` `OnSetVoiceList`（:85）：按声称系统替换语音列表
  （win11 模板：Microsoft David Desktop / Zira Desktop / Mark，en-US；与模板语言一致）。
- 地理位置/权限：无补丁，demo 侧 `session.setPermissionRequestHandler` 统一管理
  （位置只给代理 IP 所在城市坐标）。
