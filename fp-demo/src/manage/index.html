脚本库

导入前先在右侧选择目标实例。代码作为异步函数体执行，使用 return 返回结果，支持 await。

在隔离的网页 JS 环境执行，可操作 DOM，不能直接访问 Node 或宿主接口。console.log / warn / error 和返回值写入日志。10 秒等待超时不强制终止脚本；出现超时请刷新对应实例。自动执行只在主页面完整加载后触发。

扩展管理

选择包含 manifest.json 的解压目录。导入副本由项目管理；启用会在每次启动时恢复。扩展加载成功不等于全部功能兼容，弹窗、后台和存储需要分别验证。启停后请刷新已有网页。
